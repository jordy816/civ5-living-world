# The civilizations

Every civilization a game can be played with: who leads it, its gift, and what only its people build or
train. They are those of Civilization V and Gods & Kings as [Unciv](https://github.com/yairm210/Unciv) has
them, and one this mod adds: the Shoshone. At the table where a game is set up you see the same, one at
a time; here they are side by side.

This page is written by the game itself (`./gradlew :engine:test` writes `engine/build/docs/CIVILIZATIONS.md`
from the rules it plays by), so it says what the game does, in the game's own words.

- +1 Sight for Military Land units
